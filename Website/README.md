# Solar Intelligence Website

Marketing website for Solar Intelligence—data-driven solar property intelligence.

## Pages

- **Landing** (`/`) – Hero, features, and CTA
- **About** (`/about`) – Company overview and criteria
- **FAQ** (`/faq`) – Frequently asked questions
- **Contact** (`/contact`) – Contact form

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Build

```bash
npm run build
npm start
```
